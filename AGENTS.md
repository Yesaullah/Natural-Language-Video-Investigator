## Git workflow

Edit the assigned files and run tests. You may inspect Git using
read-only commands such as `git status`, `git diff`, and `git log`.

Only the human maintainer may stage changes, commit, push, change
branches, or modify Git configuration. If a Git write is needed,
show the exact command and explain why. Wait for the maintainer
to run it manually.

When finished, report the files changed and the test results.
